A small fix release. Installed copies update to it automatically.

## Fixes

- **Removing a Wi-Fi display always makes it forget this PC.** Remove now tells the display first and only removes it once it has. If the display can't be reached, it stays in the list with **Try again** and **Remove anyway**, instead of disappearing while the display still remembered the PC (which made adding it again say "already paired").
- **Adding back a display removed while it was unreachable** works without resetting it, as long as it is the same PC.
- The "QR cleared" confirmation pill has a smaller shadow that fades out fully, like the F9 popup's, instead of one that looked cut off.
