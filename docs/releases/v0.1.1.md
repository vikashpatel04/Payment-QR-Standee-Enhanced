A clean-up release. If you have 0.1.0 installed, this arrives as an automatic update.

## Changes

- **The app is in English.** The app language setting is gone. Customer-display languages are unchanged: English plus any one of Hindi, Bengali, Marathi, Telugu, Tamil, Gujarati, Kannada, Malayalam, Punjabi or Odia.
- **New installs show English only on the customer display**, and first-run setup asks for the second language. An existing install keeps its choice; change it any time in **Content → Display languages**.
- **Ports are settings.** If another program already uses port 5178 or 5179, change them in **Settings → Advanced** and restart Counter Pay.
- Nothing is tied to one billing app any more: wording says "your billing software", and the Phase 4 bill watcher is a generic, read-only database watcher each shop configures.
- Screen-reader labels on the customer display are translated.

## Install

Download **counter-pay-setup-0.1.1.exe** below. Windows may say "Windows protected your PC" (the installer isn't signed yet): choose **More info → Run anyway**.
