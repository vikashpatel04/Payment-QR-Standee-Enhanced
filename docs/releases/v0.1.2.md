A fix release. Installed copies update to it automatically.

## Fixes

- Quitting Counter Pay with the main window open could show "A JavaScript error occurred in the main process". The shutdown no longer touches History after closing it, and each shutdown step runs even if an earlier one fails.

## New

- **A log file** at `%APPDATA%\Counter Pay\logs\counter-pay.log`. Unexpected errors are written there instead of popping up at the counter. **Settings → Advanced → Open log folder** opens it, to attach when reporting a problem.
